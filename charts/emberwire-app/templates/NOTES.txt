Network mode: {{ .Values.network.mode | default "cluster" }}

  Attached to {{ include "emberwire-app.macvlanNetwork" . }} on {{ .Values.network.macvlan.master }}.
  The pod has its own MAC and IP on that VLAN, so it can see the OT segment
  directly and several instances can run on one node without colliding.
{{- else if eq (.Values.network.mode | default "cluster") "host" }}
  Host network, listening on port {{ .Values.network.hostPort }} of the node.

Get the admin password:

  kubectl get secret -n {{ .Release.Namespace }} {{ include "emberwire-app.secretName" . }} \
    -o jsonpath='{.data.admin-password}' | base64 -d

Log in:

  curl -sX POST http://{{ include "emberwire-app.fullname" . }}.{{ .Release.Namespace }}.svc.cluster.local:{{ .Values.service.port }}/auth/token \
    -H 'Content-Type: application/json' \
    -d '{"username":"{{ .Values.auth.username }}","password":"<password>"}'
